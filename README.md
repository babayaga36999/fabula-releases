# Fabula releases

Installers and update files for Fabula, a writing app for novels and screenplays.

To install: open the latest release on the right, download `Fabula_<version>_x64-setup.exe` and run it.
Windows may say "Windows protected your PC" because the installer is not code-signed: click **More info**, then **Run anyway**.

Installed copies of Fabula update themselves from here.
